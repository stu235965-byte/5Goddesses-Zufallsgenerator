5Goddesses PWA – v1.58

Wichtige Korrektur:
- Jeder Spieler besitzt einen eigenen PRIMÄR-Bereich.
- Beide Spieler teilen sich einen gemeinsamen SEKUNDÄR-Bereich.
- Ausspielen, Mornak-Platzierung, Angriffszielwahl, Primär-/Sekundärkarten-Effekte,
  Ehre, Zerstörung und relevante Rüstkammer-Effekte wurden auf das korrekte Feldschema angepasst.
- Alte Gefechts-Spielstände werden auf das neue Feldschema migriert.
- Falls ein alter Spielstand zwei getrennte Sekundärkarten enthält, bleibt eine im gemeinsamen
  Sekundärbereich; die andere wird auf die Hand ihres Besitzers zurückgegeben.

Enthält alle bisherigen Änderungen bis einschließlich v1.52 sowie die Feldkorrektur v1.58.
