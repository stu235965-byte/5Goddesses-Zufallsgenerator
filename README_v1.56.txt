5Goddesses PWA v1.56
=====================

Version: v1.56
PWA-Cache: v67

Änderungen gegenüber v1.55:
- Mobile Auto-Fit-Skalierung bleibt nach der ersten Berechnung stabil.
- Pinch-Zoom auf Android/iOS löst keine erneute Verkleinerung des Spielfelds aus.
- Die Grundskalierung verwendet den Layout-Viewport statt visualViewport.
- Bei einer echten Änderung der Bildschirmgeometrie bzw. Geräteausrichtung
  wird das Spielfeld weiterhin neu eingepasst.
