5Goddesses v1.27 – Zuflucht-Regeln

Enthalten:
- Vollständiger Daten-Audit aller vorhandenen Zufluchtkarten
- Wunder der Zuflucht: 2 Ehre -> Karte von frei gewähltem Hauptstapel ziehen
- Auswahl Entwickeln oder Wunder in VP/NP
- Stufe-2-Ausspieleffekt: +1 Physische oder +1 ASTRAL-Stärke wählen
- Zuflucht kann in der Ansturmphase angreifen, aber nur wenn keine eigene Bezwingerin auf dem Feld liegt
- Gegenangriff gegen eine angreifende Zuflucht wird mit abgewickelt
- Stufe-2-Zufluchten besitzen weiterhin das Karten-ziehen-Wunder
- Sichtbare Version: v1.27
- Service-Worker-Cache: v35

Hinweis:
Im vorhandenen Entwicklungsordner gibt es für Genova Toshi keine passende Stufe-2-Zufluchtkarte. Es wurde keine Karte erfunden oder ergänzt.
