5Goddesses PWA v1.87 – Kartenfehlerkorrekturen

Behoben:
- Begnadete Reflexe: Zielauswahl einer eigenen Bezwingerin wird nun im UI angezeigt und kann abgeschlossen werden.
- Wiederbelebungsapparatur Virus: ausschließlich im Sekundärbereich spielbar; nach dem Ausspielen wird eine gültige freie oder verdeckt belegte AZR-Zone zur Blockade angeboten. Bereits blockierte Zonen werden nicht erneut angeboten.
- Wiederbelebungsapparatur Virus kann nicht ausgespielt werden, wenn keine gültige AZR-Zone existiert.
- Zeitsprung: die nächste Versorgungsphase des Gegners wird zuverlässig vollständig übersprungen; zusätzlicher Fallback für geladene Altstände.
