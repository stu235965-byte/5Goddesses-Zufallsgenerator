5Goddesses PWA v1.53
=====================

Version: v1.53
PWA-Cache: v64

Änderungen gegenüber v1.52:
- Mobile Gefechtsansicht für Android und iOS verbessert.
- Im Hochformat wird das vollständige Spielfeld automatisch proportional
  auf die verfügbare Bildschirmfläche skaliert.
- Die normale Spielfeld-Geometrie bleibt erhalten.
- Automatische Neuberechnung bei Größen- und Orientierungsänderungen.
- Browser-Pinch-Zoom bleibt für die Detailansicht möglich.
