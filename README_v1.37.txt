5Goddesses PWA v1.37 – Mornak/Baronesse/UI-Fixes

- Baronesse Effrayer Stufe 1: +1 Ehre geht jetzt korrekt an die bereits liegende andere eigene Vengeresse, nicht an Baronesse selbst.
- Mornak-Brut: normale Karte darf offen in PRIMÄR, SEKUNDÄR oder freie eigene AZR gespielt werden. Auch beim Aufdecken aus der AZR kann der Zielbereich gewählt werden.
- Nemesis: Token-Erzeugung repariert. Ursache war ein ReferenceError durch eine nicht existierende Variable DB in createMornakTokenRuntime. Der erzeugte Token kann anschließend korrekt in PRIMÄR, SEKUNDÄR oder freie eigene AZR gelegt werden.
- Der permanente Button „Zuflucht: Entwickeln / Wunder“ wurde wieder entfernt. Zuflucht-Aktionen erscheinen nur nach Klick auf die Zuflucht.

Version v1.37, PWA-Cache v48.
