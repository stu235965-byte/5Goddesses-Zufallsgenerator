5Goddesses PWA v1.54
=====================

Version: v1.54
PWA-Cache: v65

Änderungen gegenüber v1.53:
- Mobile Gefechtsansicht weiter verbessert.
- Beide vollständigen Spielfeldseiten werden im Auto-Fit gemeinsam skaliert.
- Bezwingerinnen, Ausrüstungen, Zuflucht, AZR-Zonen, Ziehstapel,
  Entwicklungs-/Ablagestapel und Primärbereich sind direkt sichtbar.
- Horizontales Scrollen innerhalb der Spielerhälften im mobilen Auto-Fit entfernt.
- Das Spielfeld wird dafür bei Bedarf stärker verkleinert.
- Pinch-Zoom für Detailansichten bleibt möglich.
