5Goddesses PWA v1.38 – Mornak-Brut als KREATUR

- Mornak - Brut besitzt nun in der Datenbank das eindeutige regeltechnische Merkmal:
  "kreatur": true
- Der Untertyp BRUT bleibt erhalten.
- Die Karte bleibt weiterhin eine ASTRAL-Karte im Astraldeck.
- Mornak-Brut-Tokens werden aus demselben Datenbankeintrag erzeugt wie die normale
  Mornak-Brut und besitzen deshalb dieselben Kartenmerkmale; zusätzlich tragen sie
  nur die Runtime-Kennzeichnung TOKEN.
- Die Kreatur-Erkennung berücksichtigt das neue Datenbankmerkmal.
- Psilo Cybe kann damit sowohl eine normale Mornak-Brut als auch einen
  Mornak-Brut-TOKEN als KREATUR auswählen und stärken.
- Psilo selbst wird dadurch nicht als KREATUR eingestuft.

Version v1.38, PWA-Cache v49.
